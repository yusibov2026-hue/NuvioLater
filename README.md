# NuvioLater

Модифицированная версия популярного форка [`luqmanfadlli/NuvioMobile-Enhanced`](https://github.com/luqmanfadlli/NuvioMobile-Enhanced) (ветка `enhanced`) без эффекта **Liquid Glass**.

## Ключевые отличия от NuvioMobile-Enhanced
- **Убран Liquid Glass во всём интерфейсе**: отключены шейдеры, размытие и стеклянные подложки в нижней панели навигации, поиске потоков, карточках и заголовках.
- **Убран дефолтный Liquid Glass в плеере**: элементы управления видеоплеером (как в новом, так и в классическом режиме) используют чистый интерфейс без Liquid Glass по умолчанию.
- **Все функции Enhanced сохранены**: Live TV (M3U, Xtream, Stalker, EPG), трекинг (Trakt, SIMKL, AniList, WeTrakr, PublicMetaDB), загрузка торрентов/потоков в фоне, буст громкости до 200%, кастомные шрифты субтитров и синхронизация по слуху.

Готовые APK-файлы публикуются автоматически в разделе [**Releases**](https://github.com/yusibov2026-hue/NuvioLater/releases).
